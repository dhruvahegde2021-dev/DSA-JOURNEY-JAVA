## Topics Covered

### Foundation
Core Java concepts and basic problem-solving patterns that form the base for all other topics.

### Arrays
Problems involving traversal, two pointers, prefix sums, and in-place manipulation.

### Strings
Problems involving string parsing, character frequency, and pattern matching.

### Sliding Window
Fixed and variable window problems for subarray and substring optimization.

### Binary Search
Search on sorted arrays, search spaces, and binary search on answers.

### Linked List
Problems involving reversal, cycle detection, merging, and pointer manipulation.

### Stacks and Queues
Problems involving monotonic stacks, expression evaluation, and queue-based simulations.
